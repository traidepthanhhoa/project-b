Hướng dẫn cài đặt & sử dụng

  1. 1
    Tải file APK

    Nhấn nút Download executor bạn muốn.

  2. 2
    Cho phép cài đặt ngoài

    Vào Settings → Security → Install unknown apps

  3. 3
    Cài đặt APK

    Mở file vừa tải → nhấn Install

  4. 4
    Mở Roblox

    Đăng nhập Roblox và vào game

  5. 5
    Getkey

    Mở app executor → nhấn Getkey

  6. 6
    Paste & Execute

    Dán script → nhấn Execute

  1. 1
    Tải file ZIP/EXE

    Nhấn Download trên card PC

  2. 2
    Giải nén

    Dùng 7-Zip hoặc WinRAR

  3. 3
    Tắt antivirus

    Windows Defender có thể báo nhầm

  4. 4
    Dùng Microsoft Edge

    Đôi khi ít bị chặn hơn Chrome

  5. 5
    Mở Roblox

    Vào game bất kỳ

  6. 6
    Attach & Execute

    Chọn Roblox → dán script → Execute
